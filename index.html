Text Conversation Generator

Create realistic-looking text conversations.

Instructions

Write each message using:

Name: Message

The name must match one of the two names above so the generator knows which side to put the message on.

To add a timestamp, use:

[TIME: Today at 4:34 PM]

You can write anything you want inside the timestamp brackets.

Timestamps are optional. If you don't add one, none will appear automatically.
